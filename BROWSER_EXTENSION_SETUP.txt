Easy Save Audio & Video 2.1.0 - Right Click 확장 기능 설치 안내

1. ZIP 파일을 원하는 폴더에 압축 해제합니다.
2. rightclick_install.exe를 한 번 실행합니다.
3. 설치 프로그램이 확장 프로그램 파일을 자동으로 준비하고 설치된 Chrome, Microsoft Edge, 네이버 웨일의 확장 프로그램 화면을 엽니다.
4. 각 브라우저에서 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드합니다'를 선택합니다.
5. 설치 프로그램이 준비한 폴더를 한 번 선택합니다. JS 파일이나 JSON 파일을 각각 열거나 선택하지 마세요.
6. EasySaveAudioVideo_v2.1.0.exe를 실행합니다.
7. MP3 또는 동영상 탭에서 '오른쪽 마우스 메뉴 주소 복사'를 체크합니다.
8. 브라우저에서 영상 또는 링크를 오른쪽 클릭하고 '동영상 주소 복사'를 선택합니다.

참고:
- 설치 프로그램은 Chrome, Microsoft Edge, 네이버 웨일을 검색하고 발견한 브라우저의 확장 프로그램 화면을 자동으로 엽니다.
- 브라우저 보안정책상 웹 스토어에 등록되지 않은 확장 프로그램은 일반 사용자 환경에서 완전 자동 등록할 수 없습니다. 최초 1회 개발자 모드 활성화와 확장 폴더 로드는 사용자가 승인해야 합니다.
- 확장 프로그램 폴더는 %LOCALAPPDATA%\\EasySaveAudio\\browser_extension 에 자동으로 준비됩니다.
- 주소를 앱에 입력하려면 Easy Save Audio & Video 프로그램이 실행 중이어야 합니다.
- 이 기능은 주소만 입력하며 자동 다운로드를 시작하지 않습니다.
- 앱에서 체크를 해제하면 우클릭 메뉴를 눌러도 주소가 앱으로 전달되지 않습니다.
