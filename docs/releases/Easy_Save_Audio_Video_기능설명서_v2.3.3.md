# Easy Save Audio & Video 기능 설명서 v2.3.3

## 1. 주요 기능
- 웹 주소 또는 PC의 미디어 파일을 MP3로 변환합니다.
- 지원되는 웹 동영상을 다운로드하거나 로컬 동영상을 복사합니다.
- 여러 작업을 작업 목록에 등록하고 독립적으로 처리합니다.

## 2. MP3 변환
- 출력: MPEG-1 Layer III, CBR 320 kb/s, 44.1 kHz, 스테레오
- 인코더: FFmpeg libmp3lame
- 비트 저장소(Bit Reservoir): 비활성화 (Winamp 호환성 개선 시험)
- Xing/Info 프레임: 활성화 (재생시간 및 탐색 인덱스 호환성)
- 태그: ID3v2.3
- 원본 오디오는 44.1 kHz 스테레오 PCM WAV로 디코딩한 뒤 MP3로 인코딩합니다.
- 음량 정규화 필터를 적용합니다.

## 3. MP3 진단
하단의 ⌕ 버튼에서 MP3 파일을 선택하면 다음을 검사합니다.
- ID3 태그 크기 및 MPEG 오디오 시작 위치
- 첫 MPEG 프레임의 버전, 레이어, 비트레이트, 샘플레이트 및 채널 모드
- Xing/Info 및 VBRI 정보
- 파일 전체 MPEG 프레임 순차 검사: 실제 프레임 수, 프레임 오프셋, 비트레이트 분포, 샘플레이트, 프레임 사이의 간격 및 잘린 마지막 프레임
- Layer III Side Information의 main_data_begin 값과 비트 저장소 참조 프레임 수
- Xing/Info 메타데이터 프레임을 오디오 프레임 수에서 제외한 프레임 수 대조
- FFprobe 스트림 정보와 FFmpeg 전체 디코딩 결과
- 채널별 오디오 분석

진단 통과는 FFmpeg/FFprobe 검사 결과이며, 특정 플레이어의 재생을 보증하지 않습니다. Winamp 호환성은 실제 Winamp 재생 테스트로 확인합니다.

## 4. 진단 로그
앱 시작 시 이전 로그를 초기화하고 새 실행 기록을 시작합니다. 실행 중에는 로그를 계속 누적하며 자동 순환이나 크기 제한을 적용하지 않습니다. 실제 저장 한계는 운영체제와 디스크 여유 공간에 따릅니다.

## 5. 버전 기록
### v2.3.3
- 기존 CBR 320 kb/s, 44.1 kHz 스테레오, Xing/Info 및 ID3v2.3 출력 설정을 유지합니다.
- MP3 비트 저장소를 비활성화하여 Winamp 호환성을 시험합니다.
- MP3 프레임 Side Information에서 main_data_begin을 진단 로그에 기록합니다.
- Xing/Info 메타데이터 프레임이 Xing 프레임 수에 포함되지 않는 점을 반영해 진단 판정을 수정합니다.

### v2.3.1
- 192 kb/s 및 Xing 비활성화 시험 프로파일을 중단했습니다.
- 기존에 사용하던 320 kb/s CBR + Xing/Info + ID3v2.3 출력 방식으로 복원했습니다.
- MP3 전체 MPEG 프레임 순차 검사와 Xing 프레임 수 대조 진단을 추가했습니다.
- Winamp 호환성은 실제 사용자 재생 테스트로 최종 확인합니다.

### v2.3.0
- 192 kb/s CBR 및 Xing 비활성화 프로파일을 시험했습니다.
- 첫 MPEG 프레임 헤더 진단을 추가했습니다.


### v2.3.3
- Windows 실행 파일 아이콘 생성 및 EXE 포함 여부를 빌드 중 검사합니다.
- 아이콘 파일의 절대 경로를 지정해 PyInstaller에 전달합니다.
- Windows onedir 패키지의 실행 파일과 `_internal` 런타임 폴더를 함께 배포합니다.
