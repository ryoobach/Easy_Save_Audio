# Easy Save Audio & Video 기능 설명서 v2.2.8

## 1. 앱 소개
Easy Save Audio & Video는 웹 주소 또는 PC의 미디어 파일을 작업 목록에 등록해 오디오(MP3)로 변환하거나 동영상 파일을 저장·복사하는 Windows 64비트 앱입니다.

## 2. 기본 화면과 버튼
- **MP3**: 오디오 추출 및 MP3 변환을 선택합니다.
- **동영상**: 지원되는 웹 동영상 다운로드 또는 로컬 동영상 복사를 선택합니다.
- **주소**: http:// 또는 https:// 주소를 입력합니다. 웹페이지 링크나 미디어 파일을 창에 드래그해 넣을 수도 있습니다.
- **주소 붙여넣기**: 클립보드의 주소를 입력란에 붙여 넣습니다.
- **MP3 저장 위치 / 동영상 저장 위치**: 각 결과 파일이 저장될 폴더를 지정합니다.
- **추출 시작**: 대기 중인 작업을 실행합니다.
- **완료 작업 지우기**: 완료·오류·취소 상태의 작업을 목록에서 지웁니다.

### 하단 아이콘 버튼
| 아이콘 | 기능 |
|---|---|
| ✕ | 선택한 작업 취소 |
| ▤ | 작업 기록 확인 |
| ⌕ | MP3 파일 진단 |
| ☷ | 진단 로그 확인, 복사 및 저장 |

## 3. 웹 주소에서 MP3 추출하기
1. MP3를 선택합니다.
2. 웹 동영상 또는 오디오 페이지 주소를 입력하거나 드래그합니다.
3. [추출 시작]을 누릅니다.
4. 작업 목록에서 진행 상태를 확인합니다.
5. 완료된 MP3는 지정한 MP3 저장 폴더에서 확인합니다.

## 4. 동영상 저장하기
1. 동영상을 선택합니다.
2. 지원되는 동영상 페이지 주소를 입력합니다.
3. [추출 시작]을 누릅니다.
4. 완료 후 지정한 동영상 저장 폴더를 확인합니다.

웹사이트의 정책, 로그인 필요 여부, 지역 제한 및 yt-dlp 지원 여부에 따라 다운로드가 제한될 수 있습니다.

## 5. PC 파일을 MP3로 변환하기
1. 지원되는 오디오 또는 동영상 파일을 앱 창에 드래그합니다.
2. MP3가 선택되어 있는지 확인합니다.
3. [추출 시작]을 누릅니다.
4. 변환된 MP3는 MP3 저장 폴더에 생성됩니다.

지원 입력 확장자에는 MP3, WAV, M4A, AAC, FLAC, OGG, OPUS, WMA, AIFF 및 MP4, MKV, MOV, AVI, WEBM 등 주요 동영상 형식이 포함됩니다.

## 6. MP3 변환 설정
기본 출력은 MP3, 320 kb/s, 44.1 kHz, 스테레오입니다. 오디오 정규화 필터가 적용됩니다. 동일한 이름의 파일이 이미 있으면 기존 파일을 덮어쓰지 않고 시간 문자열을 붙여 새 파일로 저장합니다.

## 7. MP3 파일 진단
하단의 ⌕ 버튼을 누르고 검사할 MP3 파일을 선택합니다. 진단은 다음 항목을 확인합니다.
- 파일 크기와 오디오 스트림 존재 여부
- FFprobe JSON으로 읽은 코덱, 샘플레이트, 채널 수 및 채널 배치
- FFmpeg를 이용한 전체 오디오 디코딩 검사
- 참고용 평균 음량 측정

일반적인 출력 기준은 MP3 코덱, 44,100 Hz, 2채널(스테레오)입니다. 평균 음량을 측정하지 못한 경우에도 그 사실만으로 파일을 불량 판정하지 않습니다.

**참고:** 파일 진단 통과는 스트림 정보와 전체 디코딩 검사 결과를 뜻합니다. Winamp 등 특정 플레이어에서 실제 재생되는지까지 보증하지는 않습니다.

## 8. 진단 로그
앱을 실행할 때마다 이전 진단 로그를 초기화하고 새 로그 파일로 시작합니다. 앱이 실행 중인 동안에는 로그를 계속 누적하며, 자동 순환이나 크기 제한은 적용하지 않습니다. 따라서 로그 파일은 한 번의 앱 실행 기록만 포함합니다.
하단 ☷ 버튼을 누르면 앱의 진단 로그를 볼 수 있습니다.
- **복사**: 로그 내용을 클립보드에 복사합니다.
- **저장**: 로그를 텍스트 파일로 저장합니다.

오류가 발생하면 로그를 복사하거나 저장해 전달해 주세요. 앱 버전, 작업 이벤트, 변환 및 진단 결과를 바탕으로 원인을 확인할 수 있습니다. URL의 쿼리 문자열은 로그 기록 시 제거하도록 처리하지만, 로그를 공유하기 전에는 개인 정보가 포함되지 않았는지 확인해 주세요.

## 9. 작업 기록과 취소
- ▤ 버튼에서 최근 작업 이력을 확인할 수 있습니다.
- 실행 중인 작업을 목록에서 선택한 뒤 ✕ 버튼 또는 Delete 키로 취소할 수 있습니다.
- 여러 작업은 독립적으로 처리되며 앱이 종료되면 실행 중인 작업은 취소됩니다.

## 10. 문제 해결
- **주소가 처리되지 않음:** 주소가 올바른지, 사이트 접근이나 로그인 제한이 있는지 확인합니다.
- **변환 실패:** ☷에서 진단 로그를 저장해 전달합니다.
- **진단에서 코덱 정보를 읽지 못함:** 앱 패키지에 ffprobe가 포함되어 있는지와 진단 로그의 probe_error를 확인합니다.
- **파일 진단은 통과했지만 플레이어에서 재생되지 않음:** 해당 플레이어에서의 실제 재생 결과와 문제 파일을 별도로 확인해야 합니다.

## 11. 버전 기록
### v2.2.5
- MP3 스트림 정보 검사를 FFprobe JSON 기반으로 변경했습니다.
- 전체 디코딩 검사와 평균 음량 측정을 분리했습니다.
- 평균 음량 분석 실패만으로 파일을 불량 판정하지 않습니다.
- 인코딩 성공 후 진단 문제가 생겨도 생성 파일을 보존하고 변환 완료와 진단 경고를 구분합니다.
- 수동 MP3 진단에도 동일한 FFprobe 및 전체 디코딩 검사를 적용합니다.
- 진단 도구 ffprobe.exe와 이 기능 설명서를 Windows 패키지에 포함합니다.

### v2.2.1
- FFmpeg 입력 스트림과 null 출력 스트림을 구분하는 검증 파서를 도입했습니다.
- 진단 실패 시 생성된 MP3 파일을 삭제하지 않도록 변경했습니다.
- 하단 기능 버튼을 아이콘 전용으로 정리했습니다.


## v2.2.5 변경 사항
- Winamp에서 소리가 나지 않는 MP3 사례를 조사하기 위해 FFprobe 진단에 MPEG 오디오 프로파일, 스트림/컨테이너 비트레이트, 시작 시각, 컨테이너 형식을 추가했습니다.
- FFmpeg astats를 이용해 좌우 채널 및 전체 오디오 레벨 정보를 진단 로그에 기록합니다.
- 기존 MP3 전체 디코딩 검사와 출력 파일 보존 동작은 유지합니다.
- 주의: 진단 정보 확장 빌드이며, Winamp 실제 재생 호환성 개선은 v2.2.5 변환 파일의 사용자 재생 테스트로 확인해야 합니다.


## v2.2.5 변경 사항
- 진단 로그는 기존 파일에 이어쓰기 방식으로 기록하며, 로그 파일 크기 제한이나 자동 순환·삭제를 적용하지 않습니다. 저장 공간이 부족한 경우에는 운영체제의 디스크 용량 한계가 적용됩니다.
- Winamp에서 특정 MP3가 무음으로 재생되는 사례를 위해 MP3 출력 프로파일을 CBR 320 kb/s, 44.1 kHz, 스테레오로 유지하면서 Xing 헤더 생성을 끄도록 변경했습니다.
- ID3v2.3 출력 설정은 유지했습니다.
- 이 변경은 Winamp 호환성 개선을 위한 시험 프로파일입니다. 실제 Winamp 재생 테스트가 완료되기 전까지 호환성 해결을 보장하지 않습니다.


## MP3 원본 코덱별 변환 경로 (v2.2.5)

MP3 추출 시 원본 오디오 스트림의 코덱, 샘플레이트, 채널, 채널 레이아웃, 프로파일, 비트레이트 및 컨테이너 정보를 진단 로그에 기록합니다. 원본 코덱(Opus, AAC 등)에 관계없이 FFmpeg로 44.1kHz 스테레오 PCM 16-bit WAV 중간 파일을 생성한 뒤, 이를 MP3 320kbps CBR로 인코딩합니다. 중간 WAV는 변환 종료 후 자동 정리하며, 취소 및 실패 상황도 로그에 기록합니다. 이 변경은 Winamp 호환성을 개선하기 위한 실험 경로이며 모든 플레이어에서의 재생을 보장하지 않습니다.




## v2.2.8 변경 사항
- Winamp에서 일부 MP3가 재생을 시작하지 못하는 사례를 반영해 인코딩 호환성 프로파일을 변경했습니다.
- LAME의 강제 일반 Stereo 옵션을 제거하고 인코더 기본 스테레오 모드 선택을 사용합니다.
- Xing/Info 헤더 생성을 다시 활성화해 재생 시간 및 탐색 정보가 포함되도록 했습니다.
- MP3 출력은 320 kb/s CBR, 44.1 kHz, 2채널, ID3v2.3을 유지합니다.
- 이 변경은 표준 MP3 헤더/인코딩 경로로 되돌리는 호환성 시험입니다. Winamp 실제 재생 성공 여부는 사용자 테스트로 확인해야 합니다.

## v2.2.6 변경 사항
- 앱 시작 시 기존 진단 로그를 초기화하고 새 실행 기록으로 시작합니다.
- 앱 실행 중에는 모든 진단 이벤트를 계속 누적하며 자동 순환이나 크기 제한을 적용하지 않습니다.
- 로그 복사 및 저장 기능은 유지합니다.
